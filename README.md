# Keyboard Ambient

Нативное приложение для атмосферной подсветки клавиатуры: цвета выбранной области экрана плавно повторяются на клавишах.

Поддерживает управление через VIA и OpenRGB, выбор области захвата и калибровку цветов. Совместимость конкретной клавиатуры зависит от её прошивки и доступного управления RGB.

Целевые платформы: Linux, Windows и macOS.

Текущая версия: **0.1.0**.
