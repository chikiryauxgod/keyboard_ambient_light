# Changelog

Версии следуют Semantic Versioning. Текущая версия задаётся в файле `VERSION`.

## [Unreleased]

## [0.1.0] - 2026-11-14

### Added

- Нативное приложение на C++20 и Qt 6 для атмосферной подсветки клавиатуры.
- Захват выбранной области экрана, средний и преобладающий цвет, сглаживание переходов.
- Стандартные драйверы VIA RGB Matrix/RGB Light и подключение устройств через OpenRGB.
- Предпросмотр, тестовые цвета и отдельная калибровка RGB, яркости, гаммы и насыщенности для устройств.
- Восстановление исходных настроек подсветки при остановке и штатном выходе.
- Потоковый захват через Qt Multimedia для Windows, macOS и Wayland; захват X11 через QScreen.
- GoogleTest, тесты релизных инструментов, ASan/UBSan и отчёты покрытия.
- CI для PR, push и merge queue; ручной выпуск архивов трёх ОС с проверкой SHA-256.

### Changed

- Единый источник версии в `VERSION` для CMake, приложения и упаковки.
- Режим предпросмотра явно обозначен в кнопке запуска и строке состояния.
- Portable-сборки в `dist/<система>/` и архивы в `dist/artifacts/`, без инсталляторов и системных служб.
- Windows-архив содержит MSVC runtime DLL рядом с приложением.

### Fixed

- Подключение заголовков HIDAPI в сборках Windows (vcpkg) и macOS (Homebrew).
- Сборка Qt runtime использует абсолютный путь к выходному каталогу, необходимый для создания `qt.conf`.
- macOS CI использует поддерживаемый runner `macos-26` для ARM64.

### Known limitations

- Подсветка управляется общим цветом; поклавишная геометрия и несколько устройств одновременно пока не реализованы.
- Доступность управления RGB по радио зависит от прошивки приёмника.
- Windows/macOS и реальный сеанс Wayland требуют отдельной аппаратной проверки.
